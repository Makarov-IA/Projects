# Академические проекты по машинному обучению

В репозитории собраны два академических проекта, связанных с задачами машинного обучения и вероятностных алгоритмов:

- `Face_verification` — курсовой проект по верификации лиц с использованием сиамской нейронной сети и собственной функции потерь `CS-Loss`.
- `Project_MAB` — академический проект по задаче multi-armed bandits с акцентом на алгоритм Thompson Sampling и его модификации.

## Face_verification

Проект посвящён задаче верификации лиц. Основная идея работы — сравнить классический `Triplet Loss` с предложенной функцией потерь `CS-Loss (Cluster Separation Loss)`, которая одновременно:

- уменьшает расстояния между эмбеддингами изображений одного человека;
- увеличивает расстояния между центрами кластеров разных людей;
- сохраняет геометрическую интерпретируемость обучения.

### Результат

Согласно материалам проекта, `CS-Loss` показала лучшие результаты среди рассмотренных подходов и при этом не требует отдельной настройки майнинга триплетов, как это необходимо для `Triplet Loss`.

## Project_MAB

Проект посвящён задаче multi-armed bandits — выбору действий в условиях неопределённости с балансом между исследованием (`exploration`) и использованием уже найденной лучшей стратегии (`exploitation`).

Важно: исходный код этого проекта не сохранился. В репозитории остались только презентационные материалы.

### Назначение проекта

Этот проект оформлен как академический обзорный материал: он помогает понять, как устроены bandit-алгоритмы, чем они отличаются и в каких сценариях применяются.
